API 키

재생 모드는 키가 필요 없습니다. 키는 「라이브」로 내 질문을 직접 돌릴 때만 씁니다.

  • 키는 이 브라우저와 요청 헤더에만 있습니다. 서버는 저장하지도 기록하지도 않습니다.
  • 비용은 키 주인에게 청구됩니다 — 간단 한 바퀴 약 ₩20, 정식 약 ₩40.
  • 키는 OpenAI 계정의 API keys 화면에서 발급합니다.
  • 로컬 개발 서버로 열었다면 비워 두어도 됩니다 — 서버의 .env.local 키로 돕니다.

    딥리서치 연구소

    질문 하나를 조사관 여럿이 나눠 조사하는 과정을, 그대로 보여 주는 화면입니다.
    기본 화면의 12편은 실제로 AI를 돌려 녹화해 둔 것입니다 — 보고서도 계기판 숫자도 그때 나온 진짜 값입니다.

    1. 1소장이 질문을 절로 나누고, 조사관마다 맡을 서고와 시작 문서를 정합니다. 자료는 영문 위키백과 52건뿐입니다 — 웹 검색은 하지 않습니다.
    2. 2조사관들은 서로 무엇을 읽는지 모른 채 동시에 흩어집니다. 3만 자짜리 문서를 읽고 쪽지 300자만 들고 나옵니다. 그 쪽지만으로 원고를 씁니다.
    3. 3끝나면 LLM이 아니라 프로그램이 보고서를 서고와 대조합니다. 지어낸 출처는 없는지, 근거가 정말 그 문서에 있는지 — 계기판이 그 결과입니다.
    4. 412편은 같은 연구소에서 장치를 하나씩 끄고 돌린 것입니다. 시작 문서를 안 정해 주면? 역할을 안 주면? 빈 절을 안 되돌려 보내면? — 무엇이 무너지는지 보는 실험입니다.
